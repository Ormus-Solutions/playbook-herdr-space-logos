# A synthetic Herdr home

A stand-in for the folder the Herdr desktop app keeps its files in
(`~/.config/herdr-app`), for the demo and the tests. Nothing here is Herdr's
code. The two mods are small made-up ones that hold only the lines the patch
looks for: the `gpui-kit` import and the letter tile, written the way Herdr
0.1.15 writes them. `layouts/logos.json` stands for a layout you cloned from
Herdr's `main`, and `keys.json` for your keys.
